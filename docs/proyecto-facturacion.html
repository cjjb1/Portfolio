Facturación · Hub Transversal ERP & Fiscal Multi-Empresa

Plataforma web empresarial concebida como hub neurálgico transversal de facturación de ventas, compras, liquidación de comisiones/rappels y pasarelas ERP. Conecta en tiempo real los talleres de producción gráfica con sistemas legacy AS/400, Navision ERP y las plataformas fiscales telemáticas (FACe, AEAT/SII, UBL y Facturae).

Topología de Infraestructura, Conexiones & Servidores

Topología de Red
🖥️ Server B (Servidor Web & Aplicación)
Windows Server / IIS / PHP 7.4 · Puerto 80/443
Autenticación Windows integrada (REMOTE_USER), Router MTD, módulos de gestión y orquestación de llamadas.
🖥️ Server A (Base de Datos MySQL Central)
MySQL Server 5.7 / 8.0 (10.0.3.42) · Conexión persistente
Aloja las 5 bases de datos de empresa dedicadas más el esquema común de divisas, impuestos, países y usuarios.
⚙️ AS/400 (IBM i DB2 - DISO & EVA)
ERP Corporativo & DB2 for i · Conector ODBC persistente
Lectura de OTs y costes de talleres gráficos; replicación de facturas de compras, asientos contables y retenciones.
💼 Microsoft SQL Server (Navision & Archivo MyDoc)
SQL Server (Driver SQLSRV / ODBC Native Client)
Comprobación de cuentas contables en Navision ERP y archivo documental digital en carpetas calientes.
🏛️ Servicios Fiscales Telemáticos (AEAT & FACe)
Web Services SOAP con firma XAdES & Mutual TLS
Suministro Inmediato de Información (SII AEAT), portal FACe Facturae 3.2.2 y despacho UBL 2.1 / CII.

Reglas Críticas de Seguridad, Multi-Empresa & Auditoría

Gobernanza & Auditoría
🏢 Instancia Multi-Empresa Aislada

Conmutación dinámica de esquemas de datos dedicados (facturacion1..5) y certificados de firma digital según la entidad activa.

🔐 Autenticación Windows Delegada

Acceso transparente vía REMOTE_USER de IIS sin pantallas de login, delegando la identidad al Directorio Activo.

🛡️ Matriz de Permisos 'cruces'

Validación granular usuario-módulo con cadena de privilegios y bloqueo automático ante accesos no autorizados.

🪵 Auditoría Forense Obligatoria

Registro estructurado de cada INSERT/UPDATE/DELETE en la tabla de log con usuario, IP, SQL literal, duración y módulo.

PHP 7.4 Microsoft IIS MySQL Multi-DB AS/400 DB2 Navision ERP Facturae & XAdES AEAT SII (SOAP) UBL 2.1 & CII

Aspectos Técnicos Clave:

  • Arquitectura Multi-Empresa en Instancia Única: Motor que atiende de forma transparente a cinco razones sociales corporativas con bases de datos dedicadas y catálogo compartido, conmutando certificados digitales de firma PKCS#12 al vuelo.
  • Motor Telemático Fiscal & Firma XAdES (FACe, SII, UBL, CII): Conexión SOAP con Mutual TLS contra la AEAT (Suministro Inmediato de Información), emisión y firma de Facturae 3.2.2 ante FACe y generación de esquemas europeos UBL 2.1 y UN/CEFACT CII.
  • Casación de Compras y Sincronización Doble ERP: Validación automática de facturas recibidas contra albaranes y pedidos de compra de taller, generando asientos contables de periodificación y cierre tanto en el ERP contable de AS/400 como en Navision.
  • Archivo Documental Digital & Hot Folders: Generación desatendida de PDFs oficiales con membretes dinámicos, depósito en carpetas calientes de red e indexación bidireccional en el gestor documental mediante identificadores únicos.
  • Auditoría Forense Obligatoria: Registro exhaustivo y estructurado de cada sentencia de modificación (INSERT, UPDATE, DELETE) en base de datos, capturando usuario de red de Windows (REMOTE_USER), timestamp, IP, duración y sentencia SQL literal.
